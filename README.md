# Healthcare Data Analysis using Excel

## 📊 Project Overview

The Healthcare Data Analysis project focuses on analyzing patient and healthcare-related data using Microsoft Excel to identify important trends, patterns, and business insights.

The project includes data cleaning, analysis, Pivot Tables, charts, and dashboard creation to understand patient demographics, medical conditions, admissions, billing, and other healthcare metrics.

---

## 🎯 Project Objective

The main objective of this project is to analyze healthcare data and generate meaningful insights that can help understand patient and hospital-related trends.

The analysis aims to answer questions such as:

- What is the distribution of patients by age and gender?
- Which medical conditions are most common?
- How do patient admissions vary over time?
- What are the major billing trends?
- Which categories or conditions show higher patient volumes?
- What patterns can be identified from the healthcare data?
